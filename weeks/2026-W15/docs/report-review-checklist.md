# Report Review Checklist

Use this when you review the weekly report before sharing it.

- [ ] All repos expected are present in the report.
- [ ] Dirty repos list matches local `git status`.
- [ ] Test/lint exit codes are accurate for each repo.
- [ ] Dependency summary counts look reasonable (no missing manifests).
- [ ] Changelog highlights include the most important changes.
- [ ] Report timestamp is current for the week.
